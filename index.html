Section 1

What is an Affix?

An affix is a group of letters added to a root word. It can change the meaning or the part of speech. Tap the cards to flip them!

➕ un-PREFIX — goes at the BEGINNING
un + happy = unhappychanges the MEANING (not happy)
➖ -erSUFFIX — goes at the END
teach + er = teacherchanges the WORD CLASS (verb → noun)
🔑 Root wordthe base word
root + affix = new wordfriend + ship = friendship
